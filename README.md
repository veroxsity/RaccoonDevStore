# Raccoon Dev Store

Xbox Developer Mode apps and game ports from BanditVault, listed in one place.

Live at https://veroxsity.github.io/RaccoonDevStore/

Downloads point at each project's own GitHub release rather than a mirror, and listings link to the source where the code is public.

## Apps

- Bandit Launcher, Minecraft Java Edition on Xbox Series S and Series X

## Installing

These packages only install on a console with Developer Mode activated. A retail console will not run them.

1. Activate Developer Mode on the console and open Dev Home
2. Open the Device Portal address shown in Dev Home from a browser on the same network
3. Go to My games & apps, choose Add, then upload the downloaded package

Where a listing includes a SHA-256 file, it matches the package next to it, so the download can be checked before installing.

## Before updating

Most listings are testing builds. Back up saves and profiles first, because a new package can reset app storage if its identity changes.
