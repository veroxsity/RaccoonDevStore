Bandit Launcher runs Minecraft Java Edition on Xbox Series S and Series X in Developer Mode. It signs in with Microsoft, checks Java Edition ownership, then downloads the official game files for the version and loader you choose.

## Before installing

- Xbox Series S or Series X in Developer Mode
- A Microsoft account that owns Minecraft Java Edition
- An internet connection for sign in and first setup

This is a nightly testing build. Back up existing profiles and worlds before updating.
