A build of Bandit Launcher with native mouse support instead of the usual pointer emulation. It is a separate package from the standard Bandit Launcher, with its own LocalState, so installing it does not touch your regular profile or worlds.

## Before installing

- Xbox Series S or Series X in Developer Mode
- A Microsoft account that owns Minecraft Java Edition
- An internet connection for sign in and first setup
- The matching certificate from this listing, if your console needs it trusted separately

This is a nightly testing build.
